# 方案概览（推荐）

1. 用 ExtendScript 写一个处理单个文件夹的 JSX：打开每个文件 → 运行 `app.doAction("动作名","动作组名")` → 保存/导出 → 关闭。ExtendScript 能直接调用 Photoshop 内的动作（Action）。([Adobe Community](https://community.adobe.com/havfw69955/attachments/havfw69955/photoshop/551569/1/photoshop-scripting-guide-2020_unlocked.pdf?utm_source=chatgpt.com))
2. 用 Python 把目标文件夹路径写入临时 JSX（或把路径通过 COM 的 `DoJavaScriptFile` 调用），然后触发 Photoshop 运行这个 JSX。你可以选择通过 COM（Windows，`win32com.client.Dispatch("Photoshop.Application")`）调用 `DoJavaScriptFile` / `DoJavaScript`，或直接用 `subprocess` 启动 Photoshop 可执行文件并把 JSX 路径当参数传入。两个方法都常见并被实践使用。([营销科技助手](https://martechwithme.com/photoshop-scripting-with-python-on-windows/?utm_source=chatgpt.com))

# A. 批量处理的 ExtendScript（保存为 `batch_run_action.jsx`）

把下面脚本保存为 `.jsx`（或让 Python 在运行前把 `FOLDER_PATH` / `ACTION_NAME` / `ACTION_SET` 替换成你想要的值）：

```javascript
// batch_run_action.jsx
#target photoshop
app.bringToFront();

// ----- 配置区：如果被 Python 动态写入，请替换这三项 -----
var FOLDER_PATH = Folder.selectDialog("选择要处理的文件夹："); // 或 new Folder("/full/path")
var ACTION_NAME = "YourActionName";   // 动作名（你在 Actions 面板录制的动作）
var ACTION_SET  = "YourActionSet";    // 动作集/组名
var SAVE_OVERWRITE = true;            // 是否覆盖保存（true）或另存到子文件夹（false）
// ---------------------------------------------------------

if (!FOLDER_PATH) {
    alert("未选择文件夹，脚本终止。");
} else {
    var files = FOLDER_PATH.getFiles(/\.(jpg|jpeg|png|tif|tiff|psd)$/i);
    if (files.length === 0) {
        alert("文件夹里没有匹配的图片文件。");
    } else {
        // 可选：创建输出文件夹
        var outFolder = new Folder(FOLDER_PATH.fsName + "/_export");
        if (!outFolder.exists) outFolder.create();

        for (var i = 0; i < files.length; i++) {
            try {
                var f = files[i];
                if (f instanceof File) {
                    var doc = app.open(f);

                    // 如果动作需要特定图层选中之类，确保当前文档是活动文档
                    app.activeDocument = doc;

                    // 执行动作（Action）
                    try {
                        app.doAction(ACTION_NAME, ACTION_SET);
                    } catch (e) {
                        // 动作执行失败：记录并继续
                        $.writeln("动作执行失败: " + e);
                    }

                    // 保存逻辑：示例为覆盖原文件或保存为 JPG 到 outFolder
                    if (SAVE_OVERWRITE) {
                        // 覆盖保存 PSD/ TIFF 等原格式（示例：对非 PSD 不做额外保存）
                        // 这里简单示范：若原为 JPG 则重新另存为 JPG
                        var ext = f.name.match(/\.([^.]+)$/);
                        var lowerExt = ext ? ext[1].toLowerCase() : "";
                        if (lowerExt === "jpg" || lowerExt === "jpeg") {
                            var jpgOptions = new JPEGSaveOptions();
                            jpgOptions.quality = 10;
                            doc.flatten();
                            doc.saveAs(new File(f.fsName), jpgOptions, true, Extension.LOWERCASE);
                        } else {
                            // 对其他格式：另存为 outFolder 中同名.jpg
                            var outFile = new File(outFolder.fsName + "/" + f.name.replace(/\.[^\.]+$/, "") + ".jpg");
                            var jpgOptions2 = new JPEGSaveOptions();
                            jpgOptions2.quality = 10;
                            doc.flatten();
                            doc.saveAs(outFile, jpgOptions2, true, Extension.LOWERCASE);
                        }
                    } else {
                        // 保存到 outFolder，保持 JPG
                        var outFile = new File(outFolder.fsName + "/" + f.name.replace(/\.[^\.]+$/, "") + ".jpg");
                        var jpgOptions = new JPEGSaveOptions();
                        jpgOptions.quality = 10;
                        doc.flatten();
                        doc.saveAs(outFile, jpgOptions, true, Extension.LOWERCASE);
                    }

                    doc.close(SaveOptions.DONOTSAVECHANGES);
                }
            } catch (err) {
                $.writeln("处理文件时出错: " + err);
                // 继续下一个文件
            }
        } // end for
        alert("批量处理完成。");
    }
}
```

要点：脚本中 `app.doAction(ACTION_NAME, ACTION_SET)` 会调用你在 Photoshop 中录制好的动作（Action）。在脚本中你可以自由定义保存规则（覆盖原图、另存到子文件夹、导出 JPG/PNG 等）。([Adobe Community](https://community.adobe.com/havfw69955/attachments/havfw69955/photoshop/551569/1/photoshop-scripting-guide-2020_unlocked.pdf?utm_source=chatgpt.com))

# B. 用 Python 在 Windows 上自动运行（推荐：pywin32 + COM）

下面 Python 脚本会把上面的 JSX 模板写成临时文件（把目标文件夹路径、动作名注入），然后用 COM 命令让 Photoshop 执行它。

```python
# batch_run_py_windows.py
import os, tempfile, time
import win32com.client

# 配置（改成你要处理的文件夹和动作）
folder_to_process = r"C:\path\to\your\images"
action_name = "SelectSubjectCopy"
action_set  = "AutoTools"

# 读取 jsx 模板并替换变量（也可以直接在这里拼接）
jsx_template = r"""
#target photoshop
app.bringToFront();
var FOLDER_PATH = new Folder("%FOLDER%"); 
var ACTION_NAME = "%ACTION%";
var ACTION_SET  = "%SET%";
var SAVE_OVERWRITE = false;
// ... (其余和上面示例一样) ...
// 为简洁起见，这里建议把完整脚本内容放入模板文件并替换前三行变量
"""
# For brevity, assume you saved full script as template; here we'll just replace the three placeholders.
full_jsx_path = os.path.join(tempfile.gettempdir(), "ps_batch_temp.jsx")
with open(full_jsx_path, "w", encoding="utf-8") as f:
    content = jsx_template.replace("%FOLDER%", folder_to_process.replace("\\", "\\\\")) \
                          .replace("%ACTION%", action_name) \
                          .replace("%SET%", action_set)
    f.write(content)

# 启动/连接 Photoshop
ps = win32com.client.Dispatch("Photoshop.Application")
ps.BringToFront()

# 方法A：如果 Photoshop COM 提供 DoJavaScriptFile
try:
    # 某些 Photoshop 类型库有 DoJavaScriptFile(filename, arguments, displayDialogs)
    ps.DoJavaScriptFile(full_jsx_path, "", 1)
except Exception as e:
    # 回退：用 DoJavaScript 读取文件内容并执行
    with open(full_jsx_path, "r", encoding="utf-8") as f:
        jsx_code = f.read()
    try:
        ps.DoJavaScript(jsx_code)
    except Exception as e2:
        print("无法通过 COM 执行 JSX：", e, e2)
        raise

print("已请求 Photoshop 执行脚本（请查看 Photoshop 界面）。")
```

说明／来源：在 Windows 下通过 `win32com.client.Dispatch("Photoshop.Application")` 可以控制 Photoshop（打开/关闭文档、设置首选项、运行脚本等），并且 `DoJavaScriptFile` / `DoJavaScript` 都是常见调用方法。若某个方法不存在，可以回退到 `DoJavaScript`（把 JSX 内容作为字符串传入）。([营销科技助手](https://martechwithme.com/photoshop-scripting-with-python-on-windows/?utm_source=chatgpt.com))

# C. 不依赖 COM 的备选：用 subprocess 直接把 JSX 传给 Photoshop 可执行文件

Windows 示例（把 Photoshop 可执行文件路径改为你本机实际路径）：

```python
import subprocess, os
ps_exe = r"C:\Program Files\Adobe\Adobe Photoshop 2023\Photoshop.exe"
jsx = r"C:\path\to\batch_run_action.jsx"
subprocess.run([ps_exe, jsx], check=True)
```

在很多 Photoshop 版本下，把 JSX 文件作为 Photoshop 可执行文件的第一个参数可以让当前或新启动的 Photoshop 执行该脚本。注意：这种方式在不同版本/系统上的行为可能略有差异（某些系统上会启动 Photoshop 并执行脚本，有些则要求 Photoshop 已运行）。([Super User](https://superuser.com/questions/1614392/let-the-currently-running-photoshop-on-macos-execute-a-script-by-terminal-comma?utm_source=chatgpt.com))

macOS 可用类似方式：调用 Photoshop 的二进制并把 JSX 路径给它，或用 AppleScript 告诉 Photoshop 执行脚本（AppleScript 调用 `do javascript`）。Adobe 官方文档里也提到 macOS 可以用 Apple events 自动化。([Adobe 帮助中心](https://helpx.adobe.com/photoshop/using/scripting.html?utm_source=chatgpt.com))

# 注意事项与常见问题

* Photoshop 没有“完全无头/后台”模式：运行脚本会打开 Photoshop 窗口并显示处理进度或对话框（你可以在脚本里设置 `app.displayDialogs = DialogModes.NO` 尽量抑制弹窗，但有些插件/动作可能仍弹出交互）。([kelvin0.github.io](https://kelvin0.github.io/ImageAutomation/?utm_source=chatgpt.com))
* 要确保动作组名（Action Set）与动作名精确匹配（大小写与空格均要一致），否则 `app.doAction` 会抛错。你可先手动在 Photoshop 里确认动作能对单张图正常工作。([Adobe Community](https://community.adobe.com/havfw69955/attachments/havfw69955/photoshop/551569/1/photoshop-scripting-guide-2020_unlocked.pdf?utm_source=chatgpt.com))
* 如果你的动作包含“录制时的特定图层/选区”依赖，批处理时可能会遇不同文件格式/通道/智能对象导致的不同行为，建议先在少量样本上充分测试。
* 若脚本报“权限/文件打开错误”，请确认 Python/Photoshop 的运行用户有权限访问目标文件夹，且路径转义正确（Windows 的 `\`）。
* macOS 下推荐用 AppleScript 或直接把 JSX 当参数传 Photoshop 可执行文件来执行；Windows 下推荐用 `pywin32`（COM）因为更稳健且可以获取返回值/状态。([营销科技助手](https://martechwithme.com/photoshop-scripting-with-python-on-windows/?utm_source=chatgpt.com))
